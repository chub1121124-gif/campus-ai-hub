# 校園 AI 學生資訊交換系統

## 執行方式
```bash
pip install -r requirements.txt
python app.py
```

## 首頁
- http://127.0.0.1:5000/

## 預設帳號
### 管理員
- 帳號：admin
- 密碼：admin123

### 一般使用者
- 帳號：ming
- 密碼：user123

## 功能
- 首頁進入即為登入頁
- 使用者 / 管理員分流
- 管理員可新增、刪除所有貼文
- 管理員可刪除使用者
- 使用者只能新增、刪除自己的貼文
- 沒有帳號可註冊
- 註冊欄位：姓名、帳號、密碼、生日
- 帳號重複會提示已註冊過
